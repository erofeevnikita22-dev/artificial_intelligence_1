# технологии искусственного интеллекта

в этом репозитории находятся лабораторные работы по предмету "технологии искусственного интеллекта". код написан на python в формате jupyter notebook.

## лабораторная работа 1

первая работа посвящена повышению разрешения изображений. фотография уменьшается в 4 раза, а затем нейросеть пытается восстановить изображение исходного размера. используется небольшая модель по мотивам srgan.

для обучения берутся небольшие фрагменты фотографий. результат сравнивается с обычным увеличением bicubic с помощью метрики psnr. в ноутбуке можно посмотреть график обучения и сравнение изображений.

## запуск

файл `Lab1.ipynb` можно открыть в pycharm или jupyter notebook. для запуска понадобятся библиотеки numpy, opencv, matplotlib, pytorch и scikit-image.

```bash
pip install numpy opencv-python matplotlib torch scikit-image
```

после запуска изображения сохраняются в папку `results`. можно использовать свою фотографию, если положить файл `photo.jpg` или `photo.png` рядом с ноутбуком. если такого файла нет, программа возьмет тестовое изображение.
