# технологии искусственного интеллекта
## лабораторная работа 1

первая работа посвящена повышению разрешения изображений. фотография уменьшается в 4 раза, а затем нейросеть пытается восстановить изображение исходного размера. используется небольшая модель по мотивам srgan.

для обучения берутся небольшие фрагменты фотографий. результат сравнивается с обычным увеличением bicubic с помощью метрики psnr. в ноутбуке можно посмотреть график обучения и сравнение изображений.
